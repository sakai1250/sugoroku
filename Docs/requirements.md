# 大学院生すごろく 要件定義

## プロジェクト概要

- プロジェクト名: 大学院生すごろく
- コンセプト: 大学院生の過酷かつユーモアあふれる日常を疑似体験できる、サバイバル型ボードゲーム。
- 目的: 学費、メンタル、研究業績、徳ポイントを管理しながら修了と進路獲得を目指す。

## コアステータス

- 所持金: 生活費と学費。ゼロになるとゲームオーバー。
- 累計IF: 論文実績。修了後の進路・スコアに影響。
- メンタル: ゼロになると失踪。
- 徳ポイント: 雑務・トラブル対応で増え、救済やボーナスに影響。

## キャラクター

- 多趣味系: メンタルダメージを一回休みに変換。通常マスで逃避し、次2回のイベントを回避。
- 真面目系: 講義マスの不利効果を無効化。緊急系イベントに弱い。
- 体育会系: メンタル減少を半減。
- 金持ち: PC故障などを所持金で無効化。
- 天才肌: ジャーナル投稿時、1-6の乱数でIF加算。

## ターン状態

```text
TurnStart
→ WaitAction
→ Moving
→ MassCheck
→ Event
→ Apply
→ TurnEnd
```

現在の実装では `Moving` 後にイベントモーダルが出る場合、選択肢を押すまでターンを終了しない。
CPUは選択可能な選択肢から簡易スコアで自動選択する。

## 実装ロードマップ

### Phase 1: ゲーム基盤の整理

- 完了: プレイヤー情報を `Player1` / `Player2` 固定管理から配列管理へ変更する。
- 完了: プレイヤー人数を 1-4 人に拡張できるデータ構造にする。
- 完了: ターン管理を `currentPlayerIndex` ベースに変更する。
- 完了: プレイヤーごとの `Finished` / `Eliminated` 状態を追加する。
- 完了: 全員修了または1人以外脱落でゲーム終了する判定を追加する。
- 完了: `CpuControlled` 状態を追加する。

### Phase 2: CPU対戦

- 完了: CPUプレイヤーはターン開始後、短い待機時間を挟んで自動でサイコロを振る。
- 完了: CPUの初期実装は選択肢なしの自動進行とする。
- 完了: イベントモーダル導入後、CPUは簡易スコアで自動選択する。

### Phase 3: タイトル・設定・実績

- 完了: タイトル画面に `ゲーム開始` / `設定` / `実績` を配置する。
- 完了: 設定画面でSE音量を変更できるようにする。
- 完了: 設定画面でプレイヤー人数、CPU人数を変更できるようにする。
- 完了: 実績画面には最高スコア、修了回数、最後の進路を表示する。
- 完了: 実績データは `PlayerPrefs` 保存で実装する。

### Phase 4: イベントモーダルと選択肢

- 完了: マス到達時、中央にイベントモーダルを表示する。
